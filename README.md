# マイ投信ノート

「My投資信託」アプリ（2026年10月30日終了）の代わりとして使う、投資信託の管理アプリです。
Android のホーム画面に置いて、普通のアプリと同じように使えます（Play ストアは不要）。

## できること

- **資産**：保有ファンドの評価額・評価損益・前日比の合計と内訳
- **ウォッチ**：気になるファンドの基準価額・前日比
- **検索**：国内の公募投信 約5,800本から名前・愛称・運用会社・コードで検索（ひらがな可）
- **チャート**：基準価額の推移（1か月〜設定来）、取得単価ラインつき
- 保有は「評価額と取得額」または「口数と取得単価」のどちらでも登録可能
- バックアップの書き出し／読み込み

基準価額は 投資信託協会「投信総合検索ライブラリー」から、平日の 21:30 と翌朝 7:30 に自動取得します。
保有やウォッチの内容は**スマホの中だけ**に保存され、インターネット上には公開されません。

## 公開のしかた（初回だけ・15分ほど）

無料の GitHub を使います。パソコンでの作業がおすすめです。

1. **GitHub アカウントを作る**：https://github.com/signup （作成済みなら不要）
2. **リポジトリを作る**：右上「＋」→「New repository」
   - Repository name：`my-toushin`（好きな名前でOK）
   - **Public** を選ぶ（無料で GitHub Pages を使うため。公開されるのはアプリのプログラムと `funds.txt` のコードだけです）
   - 「Create repository」
3. **ファイルをアップロード**：作成直後の画面の「uploading an existing file」をクリックし、
   このフォルダの中身（`index.html`、`app.js`、`.github` フォルダなど**全部**）をドラッグ＆ドロップ →「Commit changes」
   - `.github` フォルダは隠しフォルダなので、エクスプローラーの「表示 → 隠しファイル」をオンにしてから選んでください
   - `data` フォルダはアップロード不要です（自動で作られます）
4. **GitHub Pages を有効にする**：リポジトリの「Settings」→ 左メニュー「Pages」→
   「Source」を **GitHub Actions** に変更
5. **初回の更新を実行**：「Actions」タブ →「基準価額の更新と公開」→「Run workflow」
   - 緑のチェックがついたら完了。表示される URL（例：`https://ユーザー名.github.io/my-toushin/`）がアプリの住所です
6. **スマホに入れる**：Android の Chrome で上の URL を開き、右上「︙」→「ホーム画面に追加」（または「アプリをインストール」）

## チャートを表示したいファンドの登録

全ファンドの最新基準価額は毎日自動で取得されますが、**チャート用の履歴**は `funds.txt` に書いたファンドだけ取得します。

1. アプリの「設定 → チャート用コードをコピー」で、保有・ウォッチ中のコードをまとめてコピー
2. GitHub のリポジトリで `funds.txt` を開き、鉛筆アイコン（編集）→ 貼り付け →「Commit changes」
3. 数分後に自動で更新され、チャートが表示されるようになります

## My投資信託からの引っ越し

My投資信託のウォッチリスト書き出し機能などで得たテキストを、「設定 → コードを一括追加」に貼り付けると、
含まれる協会コード（8桁）・ISINコードを読み取ってウォッチリストに登録します。
保有（口数・取得単価）は、証券会社のアプリの評価額・取得額を見ながら「金額で入力」で登録するのが簡単です。

## 注意

- データは機種変更やブラウザのデータ削除で消えます。「設定 → バックアップ → 書き出し」で定期的に保存してください。
- 公開リポジトリは60日間更新がないと自動実行が止まる仕様のため、月に1度だけ自動で小さな記録をコミットしています。
- 表示される情報は参考値です。正確な評価額は各証券会社でご確認ください。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` / `style.css` / `app.js` | アプリ本体 |
| `sw.js` / `manifest.webmanifest` / `icons/` | ホーム画面に追加・オフライン対応用 |
| `funds.txt` | チャートを取得するファンドのコード一覧 |
| `scripts/update.mjs` | 基準価額データの取得（GitHub Actions が実行） |
| `scripts/serve.mjs` | パソコンで動作確認する簡易サーバー（`node scripts/serve.mjs`） |
| `scripts/make-icons.mjs` | アイコン画像の生成 |
| `.github/workflows/update.yml` | 自動更新と公開の設定 |
